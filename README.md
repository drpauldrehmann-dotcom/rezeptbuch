# Unser Rezeptbuch

Web-App für Paul und Svenja: Rezepte entdecken, Schritt-für-Schritt kochen, Wochenende planen, Kühlschrank-Check, Einkaufsliste an Microsoft To Do.

- Daten: Airtable-Base „Rezepte“ (Quelle: Asana-Projekt „Rezepte“)
- Schnittstelle: n8n-Workflow „Rezeptbuch – App-Schnittstelle“ (n8n-assistent)
- Installation: Seite in Safari öffnen → Teilen → „Zum Home-Bildschirm“
